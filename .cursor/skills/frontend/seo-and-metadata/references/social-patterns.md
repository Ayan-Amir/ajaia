# Patterns

## Minimum share-preview tags

- Set `og:title`, `og:description`, `og:image`, and `og:url` on every shareable URL.
- Add `og:type` and `og:site_name` when they help clarify the content type and brand.
- Add `twitter:card` plus explicit Twitter title, description, and image when they should differ from Open Graph.

## Image rules

- Use absolute HTTPS image URLs.
- Keep preview images public, readable, and large enough for modern large-card layouts.
- Add `og:image:alt` when the image conveys real meaning.

## Ownership rules

- Keep preview metadata route-level so one URL resolves to one coherent share card.
- Treat preview images as part of the release surface; stale or placeholder images undermine otherwise correct tags.
